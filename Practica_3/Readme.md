# Práctica 3 – Visualización de Datos

En esta práctica usé el archivo `data_limpia.csv` y generé diferentes gráficas para ver mejor los sueldos.

- Histograma: muestra cómo se distribuyen los sueldos.
- Boxplot: compara los sueldos entre los años 2023 y 2024.
- Barras: enseña el promedio de sueldos por mes.
- Pie: muestra la cantidad de registros por año.
- Scatter: relación entre los meses y los sueldos.
