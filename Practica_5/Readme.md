# Práctica 5 – Modelo lineal y correlación

Usé el archivo `data_limpia.csv` para probar un modelo de regresión lineal.  
Primero creé una columna llamada **tiempo** combinando año y mes para tener un número que represente cada periodo.

Con esa columna intenté predecir el **Sueldo Neto**.  
El modelo me dio un **R² de 0.0025**, que es casi cero, así que el tiempo prácticamente no explica los cambios en el sueldo.

En la gráfica se ven todos los sueldos como puntos azules y la línea roja del modelo.  
Se nota que la recta queda casi plana y no sigue los datos.

**Conclusión:** en este conjunto de datos el paso del tiempo no tiene una relación fuerte con el sueldo.
