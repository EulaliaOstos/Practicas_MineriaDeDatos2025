# Prácticas y PIA de Minería de Datos

## Descripción
Este repositorio contiene las prácticas realizadas para la materia de Minería de Datos y el Proyecto Integrador de Aprendizaje (PIA).

El proyecto utiliza datos de sueldos de la UANL para aplicar diferentes técnicas de análisis de datos y minería de datos con el objetivo de encontrar patrones, relaciones y tendencias.

## Técnicas utilizadas
Durante el desarrollo del proyecto se aplicaron diferentes técnicas:

- Limpieza y preparación de datos
- Estadística descriptiva
- Visualización de datos
- Pruebas estadísticas (ANOVA, t-test, Kruskal)
- Modelos de regresión lineal
- Clasificación con KNN
- Clustering con K-Means
- Pronóstico de datos
- Análisis de texto (WordCloud)

## Objetivo
Analizar los sueldos registrados en la UANL para identificar patrones, comparar dependencias y aplicar técnicas de minería de datos que permitan obtener conocimiento útil a partir de los datos.

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
